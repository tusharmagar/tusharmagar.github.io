MCP setup

Connect your agent.

MCP lets Codex or Claude Code work directly inside Babylon on the same Mac. Set it up once, then control Babylon by asking your agent in plain language.

Before you start

  1. 01

    Install Babylon and move it to Applications.

  2. 02

    Open Babylon once to create its private MCP token.

  3. 03

    Keep Babylon running and open Terminal on your Mac.

Babylon and your agent must be running on the same Mac. The token stays private and is read directly from your computer.

OpenAI

Codex

Terminal
  1. 01

    Install Codex CLI

    If codex --version does not work, paste this into Terminal.

    curl -fsSL https://chatgpt.com/codex/install.sh | sh
  2. 02

    Give Codex access to Babylon

    With Babylon open, paste both lines into the same Terminal window.

    export BABYLON_MCP_TOKEN="$(cat "$HOME/Library/Application Support/Babylon Laser Studio/mcp-token")" codex mcp add babylon --url http://127.0.0.1:4519/mcp --bearer-token-env-var BABYLON_MCP_TOKEN

    The export lasts for the current Terminal window. In a new Terminal, run the first line again before starting Codex.

  3. 03

    Check the connection

    Run codex mcp list, start Codex with codex, then type /mcp. Babylon should show as connected.

Anthropic

Claude Code

Terminal
  1. 01

    Install Claude Code

    If claude --version does not work, paste this into Terminal and sign in.

    curl -fsSL https://claude.ai/install.sh | bash
  2. 02

    Give Claude access to Babylon

    With Babylon open, paste this into Terminal. User scope makes Babylon available in every project on this Mac.

    claude mcp add --transport http --scope user babylon http://127.0.0.1:4519/mcp --header "Authorization: Bearer $(cat "$HOME/Library/Application Support/Babylon Laser Studio/mcp-token")"
  3. 03

    Check the connection

    Run claude mcp list, start Claude Code with claude, then type /mcp. Babylon should show as connected.

Try it

Your first prompt

Once Babylon is connected, ask Codex or Claude Code to inspect the app before making changes.

Use the Babylon MCP. Call get_app_state, list my saved projects, and tell me which show is currently open. Do not change anything.

Laser safety: Agents can edit shows, control playback, and render previews. They cannot arm the laser or start physical laser output—you always do that yourself inside Babylon.
